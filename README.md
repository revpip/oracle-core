# Oracle Core

Oracle Core is a WordPress-first personal insight platform foundation.

This repository begins as a launchable WordPress plugin, while keeping the architecture modular enough to expand into a broader Oracle Core platform.

## Current milestone

**Sprint 0 / v0.1.0 Foundation**

Includes:

- WordPress plugin bootstrap
- Activation/deactivation hooks
- Database installer
- Settings framework
- Admin dashboard
- Question seeding
- Front-end assessment shortcode
- Scoring and result rendering
- Event logging foundation
- Safety-first wording and disclaimers

## WordPress shortcode

Add this to any WordPress page:

```text
[oracle_assessment]
```

## Important positioning

Oracle Core is not a diagnostic tool. It is designed to support structured self-reflection, highlight self-reported patterns, and encourage appropriate professional support where relevant.

## Development principle

Every future feature should increase understanding, trust, or usefulness.
